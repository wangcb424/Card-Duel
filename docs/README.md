# Card Duel website

[Play Game](https://wangcb424.github.io/Card-Duel/) · [Portfolio](https://wangcb424.github.io/portfolio/)

This folder contains the Card Duel showcase website. The embedded game build is hosted on Unity Play.

GitHub Pages serves the `docs` folder of the `main` branch. No dependencies or build step are required.

The player uses the Unity Play `build/latest/frame` URL, so publishing a new build to the same Unity Play game updates the embedded player automatically. If the game URL changes, update both occurrences in `index.html`.
